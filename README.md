## File Format
All effects are provided as SVG files, making them:
- Scalable to any size
- Editable in Figma
- Suitable for web and print
- Compatible with all major design tools
- Easy to modify and customize

## How to Use in Figma

1. **Import SVG**: Go to File > Import → Select SVG files
2. **Copy Elements**: Copy-paste effects into your design
3. **Customize**: Edit colors, fonts, sizes in Figma
4. **Combine**: Mix effects for unique variations
